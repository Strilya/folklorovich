# Background Music Library

This directory should contain royalty-free background music files (.mp3) for your reels.

## Setup Instructions

1. Download 10-15 royalty-free music tracks from:
   - YouTube Audio Library: https://www.youtube.com/audiolibrary
   - Incompetech: https://incompetech.com/music/royalty-free/
   - Pixabay Music: https://pixabay.com/music/
   - Free Music Archive: https://freemusicarchive.org/

2. Rename files with descriptive keywords:
   - epic_orchestral_01.mp3
   - calm_ambient_01.mp3
   - atmospheric_cinematic_01.mp3
   - dramatic_suspense_01.mp3
   - etc.

3. Place all .mp3 files in this directory

## Recommended Tracks

- 2-3 epic/orchestral tracks (majestic, powerful moods)
- 2-3 calm/ambient tracks (peaceful, serene moods)
- 2-3 atmospheric/cinematic tracks (mystical, flowing moods)
- 2-3 dramatic tracks (intense, suspenseful moods)
- 2-3 warm/emotional tracks (nostalgic, gentle moods)

The music fetcher (fetch_music.py) will automatically select appropriate tracks based on mood keywords in the filename.
