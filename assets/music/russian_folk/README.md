# Russian Folk Music for Superstition Reels

This directory contains Russian folk music tracks for **TYPE B (Superstition) reels**.

## Requirements

- Format: MP3
- Duration: 30+ seconds
- Style: Russian folk, traditional, ethnic, atmospheric
- Volume: Will be played at 15% (QUIET background)
- Usage: Background ambiance under narration

## How to Add Music

1. Download royalty-free Russian folk/traditional tracks from:
   - **YouTube Audio Library** (Folk/Traditional category)
     https://www.youtube.com/audiolibrary
   - **Free Music Archive** (Folk/World Music)
     https://freemusicarchive.org/
   - **Incompetech** (World/Ethnic sections)
     https://incompetech.com/music/royalty-free/
   - **Pixabay Music** (Folk/Traditional filter)
     https://pixabay.com/music/

2. Search keywords:
   - "Russian folk music"
   - "Traditional Russian"
   - "Slavic folk"
   - "Balalaika music"
   - "Russian instrumental"

3. Rename files descriptively (optional):
   ```
   russian_folk_01.mp3
   traditional_balalaika_01.mp3
   slavic_atmospheric_01.mp3
   ```

4. Place all `.mp3` files in this directory

## Recommended Tracks (10-15 tracks)

Suggested styles:
- Traditional Russian folk melodies
- Balalaika instrumentals
- Accordion-based folk music
- Atmospheric Slavic music
- Russian ethnic/world music

## Notes

- The system will randomly select one track per superstition reel
- Music plays quietly in background (15% volume) under Russian narration
- Choose atmospheric tracks that don't compete with voice
- Instrumental tracks work best (no vocals to compete with narration)
