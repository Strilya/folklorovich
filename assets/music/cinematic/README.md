# Cinematic Music for Visual Reels

This directory contains cinematic/epic music tracks for **TYPE A (Visual) reels**.

## Requirements

- Format: MP3
- Duration: 15+ seconds
- Style: Cinematic, epic, dramatic, atmospheric
- Volume: Will be played at 100% (LOUD)
- Usage: Beat-synced image transitions

## How to Add Music

1. Download royalty-free cinematic tracks from:
   - **YouTube Audio Library** (Cinematic category)
     https://www.youtube.com/audiolibrary
   - **Incompetech** (Cinematic/Dramatic sections)
     https://incompetech.com/music/royalty-free/
   - **Pixabay Music** (Cinematic filter)
     https://pixabay.com/music/
   - **Free Music Archive** (Cinematic/Soundtrack)
     https://freemusicarchive.org/

2. Rename files descriptively (optional):
   ```
   epic_orchestral_01.mp3
   dramatic_cinematic_01.mp3
   atmospheric_epic_01.mp3
   ```

3. Place all `.mp3` files in this directory

## Recommended Tracks (10-15 tracks)

Suggested moods/styles:
- Epic orchestral
- Dramatic cinematic
- Atmospheric suspense
- Powerful build-ups
- Cinematic action

## Notes

- The system will randomly select one track per visual reel
- Image transitions will be synchronized to detected beats in the music
- Music plays at full volume (100%) - choose impactful tracks
